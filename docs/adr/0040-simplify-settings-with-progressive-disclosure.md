# Simplify settings with progressive disclosure

Most users need a successful connection, so the environment-profile settings primary form keeps display name, server URL (with test connection beside it), authentication strategy, strategy-dependent credential fields, and namespace. API generation policy, write intent, timeout, cross-namespace navigation, navigation detail prefetch, and other tuning stay under Advanced. Authentication strategy sits on the primary form **before** credentials so users choose how they authenticate before filling secrets. Credential fields use progressive disclosure by **hide** (not disable): ANONYMOUS hides username and secret entirely; NACOS_PASSWORD and HTTP_BASIC show shared username + password fields; BEARER_TOKEN shows only the Token field. New profiles, empty-list seed, and Reset defaults start as **NACOS_PASSWORD** because real deployments almost always enable auth; local standalone users must pick Anonymous explicitly. Existing stored ANONYMOUS profiles are never migrated. Advanced no longer hosts authentication strategy. The chooser exposes only the P0 strategies (ANONYMOUS, NACOS_PASSWORD, HTTP_BASIC, BEARER_TOKEN) with plain-language labels and short tooltips that surface Anonymous for local Nacos without auth; legacy BASIC, TOKEN, and HYBRID remain migration-only and never appear in the chooser. API generation policy stays default AUTO (ADR 0006) and is labeled “API 版本” in the UI while domain language remains API 世代. Strategy is **chooser-only**: the form never auto-infers strategy from credentials, and incomplete credentials for NACOS_PASSWORD, HTTP_BASIC, or BEARER_TOKEN may still Apply and fail closed at runtime with ConfigurationRequired rather than silently falling back to ANONYMOUS (ADR 0007 / ADR 0008 / ADR 0011). Strategy switches clear credentials when moving to ANONYMOUS, preserve username + password between NACOS_PASSWORD and HTTP_BASIC, and never migrate secrets across any transition involving BEARER_TOKEN. Test connection runs remotely only when the strategy is ANONYMOUS or credentials are complete; otherwise it shows a local incomplete-credential message that points users at Anonymous for local unauthenticated Nacos.
