# Report every observation to the access-visibility module

Access-blocked state is owned by a dedicated module and consumed by the cache when it reads, rather than being owned by the cache or consulted by each caller before reading. This refines ADR-0044, which kept the visibility-block gate out of the cache module so that the cache would not also own the dataset-confirmation state machine: ownership stays outside, but the cache depends on it, because "every read remembers to ask first" is a convention this codebase has broken four times — fourteen of sixteen cache mutations skipped their gate, one of four writers skipped the tombstone, the two protocol adapters drifted apart in four places, and the detail panel inlined the same fencing check seven times. Code navigation also reads a cache snapshot directly rather than through the gateway, so a caller-side check could not cover every read even in principle.

The observation high-water is one primitive with two scope users: the cache keys it by configuration coordinate, the visibility module by access identity, capability, and optional namespace. Each module keeps its own single mutation entry point, so neither can be bypassed, but the ordering logic exists once — ADR-0044 already merges the two implementations that exist today, and rebuilding a second one here would recreate exactly what it resolved.

The gateway reports **every** completed operation to the visibility module — successes as well as typed failures — with its observation sequence and its operation class. Successes are not incidental: ADR-0019 clears a scoped block only on a matching success, so a module that saw only failures could block and never unblock, and a stuck block presents as the plugin showing nothing at all, which is harder to diagnose than a missing block. The gateway is also the only place that still knows which operation produced a result, and ADR-0019 scopes blocks by exactly that: a permission denial on a configuration read blocks an identity and namespace, while the same denial on publishing, namespace discovery, or another capability must never hide authorized read data.
