# Choose the suggested Namespace from isolated discovery

The settings Namespace field is the profile's suggested Namespace (a preference that seeds a new project session), not the live project-session Namespace. It is an editable, filterable combo: Test Connection's isolated discovery stage supplies options (display name shown, Namespace ID stored), typing an ID remains valid when discovery has not run or is forbidden, and changing endpoint, API-generation policy, or authentication inputs clears options while keeping the typed identifier. Connection diagnosis still treats a readable configured Namespace as connected, but it always attempts discovery after generation resolution even when that read fails, so a wrong or forbidden ID can still fill the chooser; a permission-denied read is 访问受阻 and must not be headlined as connection failure.
