# One protocol core and two dialects, with graded capabilities

The execution shell has exactly one implementation: authentication, request budget, transport, retry, the handling of each classified failure, and value normalisation. Each API generation supplies only how to build its requests and how to classify its responses into the shared failure vocabulary. Every divergence found between the two adapters — a tenant value normalised one way and not the other, a request budget enforced on one generation and entirely absent on the other, the same bare status mapped to two different failures, and one generation keeping a private access-token store outside the shared authentication session registry — has the same cause: a cross-cutting concern owned twice. Shared helper functions were rejected as the remedy because that is the arrangement in place today; the divergences arose precisely from each side remembering to call them, and deciding what a classified failure *means* must be written once or the two generations will keep producing different product behaviour from the same server response.

Protocol capabilities are **graded and declared by the dialect**, not binary and not derived from the API generation. ADR-0013 requires optional behaviour to be an explicit capability, and the natural reading of that — separate capability interfaces the gateway tests for at dispatch — has already been implemented and is dead: both adapters implement all of them, so the checks can never fire and the unsupported-capability failure is unreachable in production while a controller handles it as a possible state. The real variance is not presence but degree: namespace discovery and content search both work on both generations, with different coverage. The graded form of that already exists, but as a free function switching on the generation, consumed by an upper layer — the exact branch ADR-0013 forbids. Moving the grade onto the dialect satisfies both halves of that decision, and makes the unsupported-capability failure meaningful for the first time, since it then arises only when a dialect genuinely declares a capability absent.
