# Keep one persisted environment model and edit intents, not profiles

Environment configuration is persisted as environment profiles only. The legacy server list and the flat active-server mirror become deserialization inputs, migrated once and never written again, so nothing is derived from anything at read time. Today three representations of the same thing coexist — the flat fields, the legacy server list the settings dialog edits, and the profiles every runtime path reads — and profiles are derived from the server list *lazily, on read*. That is why six read-named methods mutate persisted state and one of them writes to the credential store, and why a chain reachable from four Swing call sites can migrate settings on the event dispatch thread. Removing the source removes the derivation.

The settings dialog edits **profile intents**: the attributes a user chooses, without the profile revision, access revision, or credential slot id. The store compares an intent against the stored profile when it writes, and computes those derived values itself. This collapses the five independent definitions of "has this changed" that exist today — one keyed by id over all fields, one positional over twelve of thirteen, one a five-field signature that omits the credential and the generation policy, one over six fields inside the profile, and one comparing against the credential store — into a single answer produced in one place, which is the revision itself. Letting the dialog edit whole profiles and simply agreeing not to touch the revisions was rejected: a revision is part of the access identity that partitions the cache, so an accidental edit is a silent cache-partition error, and this codebase's record with conventions of that kind is poor. As a consequence, opening or cancelling the settings dialog cannot persist anything, because the dialog holds only intents and the store is the only writer — the current behaviour, where merely opening Settings rewrites the application-wide default to the current project's selection, has no path to reproduce.
